### D-30 · An optional editor engine binding

Crystal React ships RichTextEditor from @crystal-ui/react/editor, binding TipTap 3 to Crystal's format vocabulary with TipTap as optional peers. It was built on the brief's authority ahead of this ruling. Every platform library will meet the same request, so the catalogue should say whether a library may do this.

- (a) A library may ship an optional binding from its own entry point, the engine an optional peer; the catalogue names the format vocabulary as the contract **(rec.)**. C-T2 becomes ready; unblocks R-T7.
- (b) Bindings live outside the libraries, as separate packages. C-T2 becomes ready; adds R-T10, Move RichTextEditor into its own package; unblocks R-T7.
- (c) No bindings; remove @crystal-ui/react/editor. C-T2 becomes ready; R-T3 is dropped; R-T7 is dropped; adds R-T10, Remove @crystal-ui/react/editor; D-33 no longer needs a ruling.

**Ruled: (a) A library may ship an optional binding from its own entry point, the engine an optional peer; the catalogue names the format vocabulary as the contract.** By Meridian Digital, 2026-10-02.

### D-37 · Selection that travels between segments

When the choice changes in tabs, a segmented control, the dock, bottom navigation or a toggle button group, the old segment's fill switches off and the new one's switches on: Crystal paints selection on each item, and the only motion is selection's squash in place (tab-in plays on the panel, not the tab). surfaces.json describes .cr-indicator as "the moving pill behind a selected segment", but crystal.css draws no such pill, and no recipe moves a selection from one place to another. A travelling pill is motion a person starts, so the rule that nothing moves at rest allows it; it is a visible change to every strip, so it is Meridian's to approve.

- (a) Specify a travelling pill for every strip: one .cr-indicator.pill behind the selected segment, moved by a new critically damped recipe between measured positions, on tabs, the segmented control, the dock, bottom navigation and toggle button groups; selection stays label weight **(rec.)**. C-M3 becomes ready; adds R-A8, The travelling selection pill on strips.
- (b) Only where a choice is a position along one strip, tabs and the segmented control; the dock, bottom navigation and button groups keep selection in place. C-M3 becomes ready; adds R-A8, The travelling selection pill on strips.
- (c) Keep selection in place, and correct surfaces.json so it no longer describes a moving pill. C-M3 becomes ready.

**Ruled: (a) Specify a travelling pill for every strip: one .cr-indicator.pill behind the selected segment, moved by a new critically damped recipe between measured positions, on tabs, the segmented control, the dock, bottom navigation and toggle button groups; selection stays label weight.** By Meridian Digital, 2026-10-02.
