Verification and limits

Checks executed September 17, 2026. This is evidence about this reference package, not production application readiness or complete WCAG conformance.

Executed checks

  • 1716 solid-pair and bounded composite contrast cases; 0 failures. Minimum normal-text result: 4.67:1. Essential non-text cases use their separate 3:1 threshold.
  • All six palettes in both modes, scene navigation, appearance controls, preference restoration, reduced effects and keyboard dialog focus behavior exercised in the browser.
  • Responsive scenes at 320px and 390px, plus final material studies at 320px, checked for page overflow.
  • CSS and JSON files actually downloaded through the UI and inspected for the current configuration, both modes and updated material parameters.
  • Plastic opacity and inactive fallback, 40px Frost diffusion, and Resin appearance checked.
  • Five immutable Gather specification copies verified against their SHA-256 manifests and the original files.
  • 14 HTML pages and 484 local links/assets checked; 0 errors.
  • Motion 13.4.0 and GSAP 3.15.0: 16 real-browser contracts passed, 0 failed, covering all 54 recipes and the material signatures.

Scope and limitations

The contrast model checks Resin/Haze control labels with optical sheen beneath the protective fill, declared solid pairs, foundation combinations, 80%/79% content composites and RGB-corner backdrops with the fixed 20% Resin fill and mode-specific Stone fill and optical sheen. It is not a pixel-level audit of every possible image or layout. Native materials, screen readers, full zoom/assistive workflows, and cross-browser coverage remain adoption checks. Forced-colors rendering was tested in both high-contrast palettes and is recorded in the captures below.

The HTTP preview was tested. The browser's URL policy blocked a direct file-URL test; no workaround was attempted. The files use relative local assets, but direct-file execution is not claimed as browser-tested.

The initial native dialog allowed Tab to leave the document for browser chrome. Explicit focus wrapping was added, then containment, Escape and focus return passed. The Harbor light contextual-text and Harbor dark glass extremes were corrected before the final contrast run.
